# Vending

A bright retro vending machine with coins, keypad selection, stock, change and a printed sales tape. Built with plain HTML, CSS and JavaScript.

**Live demo:** https://ayo-2010.github.io/vending/

## Features

- Twelve stocked drinks across three shelves and four columns
- Insert ¥10, ¥50, ¥100 and ¥500 coins with a live credit display
- Buy by clicking a drink, pressing its keypad code, or typing a code such as `B2`
- Stock counts, sold-out states and low-stock dots on every product
- Animated collection tray for each dispensed drink
- Change return broken down into coins
- Sales tape with item, time, price, daily total and can count
- Restock mode for refilling shelves and resetting the machine
- Print action for the sales tape
- Stock, credit and sales saved in localStorage
- Responsive layout down to 390px, reduced motion support and a global `[hidden]` rule

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
